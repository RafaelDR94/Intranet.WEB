# getTabsFromPath

Devuelve las pestañas que corresponden a la sección actual de la ruta `/main-page`.

```ts
const tabs = getTabsFromPath('/main-page/home')
```

Retorna un arreglo de objetos con `label` y `path` para usar en la navegación del layout principal.
