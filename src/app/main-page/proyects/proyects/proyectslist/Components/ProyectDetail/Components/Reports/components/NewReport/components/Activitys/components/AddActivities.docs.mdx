# AddActivities

Panel principal para capturar evidencias fotograficas del reporte. Combina un
visor de actividades, el uploader expandido y un formulario dinamico para editar
los metadatos de cada actividad.

---

## Uso rapido

```tsx
import AddActivities from "./components/AddActivities";

<AddActivities hideAdd={false} />;
```

## Que resuelve

- Gestiona los estados de seleccion, edicion y confirmacion de borrado.
- Reutiliza `DynamicForm` para la metadata y `ImageUploaderExpanded` para las
  imagenes.
- Expone un `PopUp` interno que confirma eliminaciones antes de actualizar la
  tienda de actividades.
