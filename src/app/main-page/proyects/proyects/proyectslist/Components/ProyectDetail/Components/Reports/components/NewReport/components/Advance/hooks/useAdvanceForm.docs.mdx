# useAdvanceForm

Orquesta el formulario principal del paso Avance. Ajusta la estructura segun el
modelo del reporte, rellena valores iniciales y propaga los cambios al builder.

```tsx
const {
  formFields,
  canStart,
  formId,
  onFormSubmit,
  onFormValidChange,
  handleValuesChange,
} = useAdvanceForm(modelName);
```

## Detalles relevantes

- Usa `useFormFieldsStore` para cachear la configuracion del formulario y
  refrescarla solo cuando cambia el modelo.
- Pide ubicaciones y categorias en paralelo, actualizando los selects con los
  helpers del store y mostrando alerts cuando algo falla.
- Normaliza valores y notifica a `updateAdvance` cada vez que el usuario
  modifica campos clave (ticket, fechas, progreso, etc.).
