# DevicesList

Tabla de dispositivos disponibles para la ubicacion seleccionada. Usa
`useDevicesList` para obtener filas, manejar seleccion y exponer un popup de
confirmacion al eliminar.

---

## Uso rapido

```tsx
<DevicesList onCreate={openForm} onEdit={editDevice} />;
```

## Caracteristicas

- Habilita busqueda interna y seleccion multiple cuando el reporte aun no esta
  firmado.
- Ajusta las columnas para vista movil, dejando solo la Información esencial.
- Muestra estados vacios cuando no hay ubicacion o cuando la lista de dispositivos
  retorna vacia.
