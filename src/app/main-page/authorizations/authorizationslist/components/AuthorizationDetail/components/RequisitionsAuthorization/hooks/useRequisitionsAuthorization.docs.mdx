# useRequisitionsAuthorization

Hook que carga requisiciones, documentos y estado de autorización para el flujo de aprobación.

```ts
const {
  rows,
  columns,
  isPendingStatus,
  handleStartApproval,
} = useRequisitionsAuthorization()
```
