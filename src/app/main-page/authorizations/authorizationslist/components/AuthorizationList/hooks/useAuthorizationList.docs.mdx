# useAuthorizationList

Hook que centraliza el estado del listado de autorizaciones, incluyendo columnas, filtros y refresco.

```ts
const {
  columns,
  rows,
  filterOptions,
  filterValue,
  handleFilterChange,
  handleRefresh,
} = useAuthorizationList()
```
