# Utilidades de RequisitionsForm

Funciones auxiliares para manejar catálogos y construir payloads.

- **computeLoadingFormInfo**: evalúa si los catálogos están listos.
- **getOptionLabel**: obtiene la etiqueta de un valor.
- **buildRequisitionPayload**: genera el objeto a enviar al backend.
- **createInitialFields**: prepara los campos iniciales del formulario.
