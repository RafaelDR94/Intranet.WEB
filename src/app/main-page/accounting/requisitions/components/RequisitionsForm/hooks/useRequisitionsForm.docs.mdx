# useRequisitionsForm

Maneja la lógica y envíos del formulario de requisiciones.

- `fields`: campos del formulario.
- `loadingFormInfo`: indica si los catálogos se están cargando.
- `setFormReady(boolean)`: marca si el formulario está listo.
- `handleSubmit(values)`: procesa el envío.
- `onSubmit()`: dispara el submit externo.
- `buttonDisabled`: bandera para el botón guardar.
