# useDetailsPanel

Maneja el envío de comentarios, validación o rechazo de una factura desde el panel de detalles.

```ts
const {
  labels,
  handleSubmitComment,
  handleSubmitReject,
  handleSubmitValid,
} = useDetailsPanel({ selected, rejectType, setPanelOpen, operations });
```
