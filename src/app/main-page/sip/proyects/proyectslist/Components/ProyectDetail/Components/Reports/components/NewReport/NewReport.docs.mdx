# NewReport

Wizard que guia la captura de un reporte SIP en pasos: avance, actividades,
equipos, mapas, refacciones y firma. Cada paso monta su submodulo e integra la
logica del hook `useNewReport`.

---

## Contexto requerido

- Debe ejecutarse dentro de los proveedores de la página (`AuthProvider` y
  `PrincipalProvider`) para acceder a permisos, alertas y spinners.
- Consume los stores de reportes (`useReportsStore` y `useReportBuilderStore`)
  creados con Zustand; no requiere providers adicionales.
- Lee parámetros de URL mediante `useQuery` para continuar flujos abiertos.

---

## Uso rápido

```tsx
import NewReport from "./NewReport";

export default function NewReportPage() {
  return (
    <AuthProvider>
      <PrincipalProvider>
        <NewReport />
      </PrincipalProvider>
    </AuthProvider>
  );
}
```

El componente muestra el layout de formulario (`FormsLayout`) con acciones
primarias/deshabilitadas segun la validez que expone `useNewReport`. Cada paso
delegado puede reportar su validez mediante las callbacks recibidas.
