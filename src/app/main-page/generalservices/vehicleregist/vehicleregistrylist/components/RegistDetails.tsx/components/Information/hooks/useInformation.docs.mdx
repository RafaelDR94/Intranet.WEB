# useInformation

Extrae y normaliza la información del seguimiento vehicular para `Information`.

```tsx
const {
  assignment,
  generalRows,
  departure,
  arrival,
  checklistDefinitions,
} = useInformation()
```

---

## Tareas

- Determinar salida y llegada con `findDepartureAndArrival`.
- Formatear kilometrajes (`formatMileage`), combustible (`formatFuelLevel`) y
  observaciones (`formatRemarks`).
- Construir arrays para checklists de herramientas/documentos usando los
  helpers `TOOL_CHECKLIST` / `DOCUMENT_CHECKLIST`.

---

## Utilidades exportadas

- `formatFuelLevel`, `formatMileage`, `formatRemarks`.
- `buildVehicleName` y `findDepartureAndArrival`.

Estos helpers se testean individualmente para asegurar consistencia de formato.
