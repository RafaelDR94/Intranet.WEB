# useArrivePictures

Instancia de `createVehiclePicturesHook('arrive')` que entrega fotografías de
entrada del vehiculo.

```tsx
const { items, loading, error, hasAssignment, refresh } = useArrivePictures()
```

Ideal para componer vistas que necesiten únicamente la galería de llegada.
