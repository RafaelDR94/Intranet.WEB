# ArrivePictures

Versión para fotografías de llegada. Comparte estructura con `DeparturePictures`
pero usa el folder `arrive` para cargar evidencias.

---

## Hook asociado

- `useArrivePictures` (factory `createVehiclePicturesHook('arrive')`).

---

## Estados cubiertos

- Sin asignación seleccionada.
- Cargando imágenes.
- Error en la descarga.
- Galería vacía.
- Galería completa (`ActivitiesViewer`).
