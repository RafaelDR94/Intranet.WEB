# useDeparturePictures

Wrapper generado por `createVehiclePicturesHook('departure')`. Expone la misma
interfaz que `useVehiclePictures` pero fijando el folder de salida.

```tsx
const { items, loading, error, hasAssignment, refresh } = useDeparturePictures()
```

Utilícelo cuando necesite mostrar fotografías de salida en otros componentes o
stories aislados.
