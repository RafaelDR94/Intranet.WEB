# ThemeContext

Proporciona el tema global de la aplicación y permite alternar entre `light` y `dark`.

```tsx
<ThemeProvider>
  <App/>
</ThemeProvider>
```

Usa el hook `useTheme()` para acceder al valor actual y la función `toggleTheme`.
