# FirebaseContext

Inicializa y provee instancias de Firebase (`storage`, `database`, `messaging` y `auth`). Exponer hooks de ayuda como `useFirebaseStorageHelper` y `useFirebaseRealtimeHelper`.

Envuelve la aplicación con `<FirebaseProvider>` para poder usar sus utilidades.
