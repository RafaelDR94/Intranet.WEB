# useFirebaseMessagingHelper

Proporciona funciones para obtener el token de Firebase Messaging y escuchar mensajes en primer plano.

```ts
const { getMessagingToken, onMessageReceived, notification } = useFirebaseMessagingHelper(messaging)
```
