# PrincipalContext

Centraliza múltiples hooks globales como `useTheme`.

Actualmente proporciona el acceso a `useTheme` y `useAlert` a través del wrapper `PrincipalProvider`.

## Uso

```tsx
import { PrincipalProvider } from '@/app/context/ThemeContext/PrincipalContext';

<PrincipalProvider>
  <App />
</PrincipalProvider>
```

Todos los hooks expuestos se obtienen con `usePrincipal`.
