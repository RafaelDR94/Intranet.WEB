# BillingDocuments utilities

Funciones auxiliares para realizar operaciones CRUD sobre documentos de facturas.

| Utilidad | Descripción |
| --- | --- |
| `fetchBillingDocuments` | Obtiene la lista de documentos |
| `fetchBillingDocumentById` | Obtiene un documento por su ID |
| `fetchBillingDocumentByIdRequisition` | Obtiene documentos por requisición |
| `fetchBillingDocumentCategories` | Obtiene las categorías disponibles |
| `fetchBillingDocumentDescriptions` | Obtiene las descripciones disponibles |
| `fetchExpenseTypeCatalog` | Obtiene el catalogo de tipos de gasto |
| `fetchSatBillingDocument` | Obtiene información SAT de los documentos |
| `createBillingDocument` | Crea un nuevo documento |
| `updateBillingDocument` | Actualiza un documento existente |
| `deleteBillingDocument` | Elimina un documento |
| `rejectBillingDocument` | Rechaza un documento |
| `validateBillingDocument` | Valida documentos seleccionados |
| `validateBillingDocumentOperations` | Valida documentos desde operaciones |
| `sendToSapBillingDocument` | Envía documentos validados a SAP |
