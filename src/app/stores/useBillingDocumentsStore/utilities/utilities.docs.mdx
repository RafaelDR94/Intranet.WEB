# BillingDocuments utilities

Funciones auxiliares para realizar operaciones CRUD sobre documentos de facturas.

| Utilidad | Descripción |
| --- | --- |
| `fetchBillingDocuments` | Obtiene la lista de documentos |
| `fetchBillingDocumentById` | Obtiene un documento por su ID |
| `createBillingDocument` | Crea un nuevo documento |
| `updateBillingDocument` | Actualiza un documento existente |
| `deleteBillingDocument` | Elimina un documento |
