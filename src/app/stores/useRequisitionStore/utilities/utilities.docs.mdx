# Requisition utilities

Funciones auxiliares para gestionar requisiciones.

| Utilidad | Descripción |
| --- | --- |
| `fetchRequisitions` | Obtiene la lista de requisiciones |
| `fetchRequisitionsByIdEmployee` | Obtiene requisiciones por empleado |
| `fetchRequisitionsByDate` | Obtiene requisiciones por rango de fechas |
| `fetchCurrentRequisition` | Obtiene la requisición actual |
| `createRequisition` | Crea una nueva requisición |
| `updateRequisition` | Actualiza una requisición |
| `deleteRequisition` | Elimina una requisición |
| `updateExcelRequisition` | Genera un Excel de requisiciones |
| `downloadRequistionResume` | Descarga el resumen de una requisición |
