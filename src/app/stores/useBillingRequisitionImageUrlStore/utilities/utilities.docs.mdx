# BillingRequisitionImageUrl utilities

Utilidades para consultar y actualizar la evidencia de aprobación (imagen) ligada a una requisición.

| Utility | Descripción |
| --- | --- |
| `fetchBillingRequisitionImageUrlById` | Obtiene la URL de evidencia por id de requisición. |
| `updateBillingRequisitionImageUrl` | Actualiza la URL de evidencia en el backend. |

## Ejemplo de uso

```ts
import { useBillingRequisitionImageUrlStore } from '../useBillingRequisitionImageUrlStore'

const { updateRequisitionImageUrl } = useBillingRequisitionImageUrlStore.getState()

await updateRequisitionImageUrl({
  idRequisition: 'REQ-123',
  imageUrl: 'https://.../evidence.jpg',
})
```
