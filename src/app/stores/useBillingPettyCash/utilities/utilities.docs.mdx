# BillingPettyCash utilities

Funciones auxiliares para gestionar fondos y vales de caja chica.

| Utilidad | Descripción |
| --- | --- |
| `fetchPettyCashFunds` | Obtiene los fondos de caja chica |
| `fetchPettyCashFundById` | Obtiene un fondo por ID |
| `createPettyCashFund` | Crea un nuevo fondo |
| `updatePettyCashFund` | Actualiza un fondo |
| `deletePettyCashFund` | Elimina un fondo |
| `updateCashOnHand` | Actualiza el efectivo en caja |
| `fetchPettyCashVouchers` | Obtiene los vales de caja chica |
| `fetchPettyCashVoucherById` | Obtiene un vale por ID |
| `createPettyCashVoucher` | Crea un nuevo vale |
| `updatePettyCashVoucher` | Actualiza un vale |
| `deletePettyCashVoucher` | Elimina un vale |
| `rejectPettyCashVoucher` | Rechaza un vale |
| `validatePettyCashVoucher` | Valida un vale |
