# BillingImages utilities

Funciones auxiliares para gestionar imágenes de facturas.

| Utilidad | Descripción |
| --- | --- |
| `fetchBillingImages` | Obtiene la lista de imágenes |
| `fetchBillingImageById` | Obtiene una imagen por ID |
| `createBillingImage` | Crea una nueva imagen |
| `updateBillingImage` | Actualiza una imagen existente |
| `deleteBillingImage` | Elimina una imagen |
| `rejectBillingImage` | Rechaza una imagen |
