# PictureHelper

Funciones para manipular imágenes en formato base64 y archivos:

- `base64ToBlob(base64)` transforma un DataURL en `Blob`
- `compressImage(url, q)` comprime una imagen
- `getBase64FileSizeInKB(dataUrl)` obtiene su tamaño en KB
- `urlToBase64(url)` convierte una URL en base64
