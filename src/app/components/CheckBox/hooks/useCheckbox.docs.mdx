# useIndeterminate

Hook que permite marcar un elemento `input[type=checkbox]` como **indeterminate**.

```tsx
const ref = useRef<HTMLInputElement>(null)
useIndeterminate(ref, true)
```

El hook actualiza la propiedad `indeterminate` cada vez que cambia el valor.
