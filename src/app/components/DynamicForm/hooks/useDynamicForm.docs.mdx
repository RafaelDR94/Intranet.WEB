# useDynamicForm

Hook que expone utilidades para manejar formularios dinámicos:

- `initialValues`: valores iniciales según los campos
- `validationSchema`: esquema de validación construido con Yup
- `resolveVariant`: determina el estilo de un campo
- `cleanValues(values)`: limpia campos ocultos
