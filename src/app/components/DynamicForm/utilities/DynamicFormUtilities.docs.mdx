# Utilidades de DynamicForm

Funciones auxiliares usadas por `useDynamicForm`.

- **getInitialValues**: crea los valores iniciales
- **getValidationSchema**: genera el esquema de Yup
- **cleanHiddenFields**: limpia campos no visibles
- **resolveVariant**: determina el estilo del campo según validaciones
