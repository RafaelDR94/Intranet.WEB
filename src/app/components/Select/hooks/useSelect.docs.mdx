# useSelect

Maneja el estado de apertura y selección de un componente Select. Devuelve:

- `open`: si la lista está abierta
- `ref`: referencia al contenedor
- `toggleOption(value)`: agrega o quita el valor
- `setOpen(boolean)`: abre o cierra manualmente
